# Frontend Tier

This directory contains the client-side user interface of the Nova E-Commerce platform.

## Directory Structure

- `index.html`: Main HTML5 storefront including navigation, mega-menus, hero banner, featured products, one8 Virat Kohli footwear showcase, Men's & Women's collections, electronics gallery, dynamic slide-in cart drawer, and interactive checkout modal.
- `css/`:
  - `style.css`: Primary styling, modern responsive layout, gradients, mega-menus, typography, and product cards.
  - `cart.css`: Slide-in cart drawer styles, animations, order summary modal, and notifications.
- `js/`:
  - `script.js`: Interactive client logic, cart state management (add/remove/update qty), coupon code calculations, and product catalog data.
- `images/`:
  - `hero-bg.jpg`: High-resolution hero background image.
  - `one8-black-urban.jpg`: one8 Virat Kohli Core Black Urban Sneaker.
  - `one8-blue-runner.jpg`: Puma x one8 Virat Kohli V-Speed Slip-On.
  - `one8-maroon-sneakers.jpg`: one8 Virat Kohli Maroon Classic Sneaker.
  - `one8-white-court.jpg`: one8 Virat Kohli Court White & Teal Sneaker.

## Running Locally

You can open `index.html` directly in any web browser, host it via static servers (like GitHub Pages or Nginx), or serve it through the Flask backend at `http://127.0.0.1:8080`.
