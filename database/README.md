# Database Tier

This directory contains the database schema, seed data, and initialization tools for the Nova E-Commerce application.

## Directory Contents

- `schema.sql`: DDL defining the relational schema (`categories`, `products`, `users`, `orders`, `order_items`).
- `seed_data.sql`: DML inserting initial categories and 44 catalog products across multiple collections (Watches, Bags, Footwear, Audio, Apparel, Tech, and one8 by Virat Kohli sneakers).
- `init_db.py`: Python CLI tool to create and seed the SQLite database (`ecommerce.db`).
- `ecommerce.db`: Local SQLite database file (generated by `init_db.py`).

## Quick Setup

To initialize or reset the local SQLite database, run:

```bash
python database/init_db.py
```

## Schema Overview

- **`categories`**: Product classifications (`name`, `slug`, `description`).
- **`products`**: Store items with price, discount/offer, image URL, category, stock.
- **`users`**: Registered customers (`name`, `email`, `password_hash`).
- **`orders`**: Customer checkout records with shipping address, status, and total.
- **`order_items`**: Line items linked to orders with product details and quantity.

## Production Databases (PostgreSQL / MySQL)

The SQL files are written with standard ANSI SQL conventions and can be executed directly against PostgreSQL, MySQL, or AWS RDS instances:

```bash
# PostgreSQL
psql -h <host> -U <user> -d <dbname> -f database/schema.sql
psql -h <host> -U <user> -d <dbname> -f database/seed_data.sql

# MySQL
mysql -h <host> -u <user> -p <dbname> < database/schema.sql
mysql -h <host> -u <user> -p <dbname> < database/seed_data.sql
```
